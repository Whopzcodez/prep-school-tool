# PrepSchool

PrepSchool is an adaptive interview-preparation platform for individual candidates preparing for technology-industry roles.

## Initial tracks
- Software Engineering
- Cloud / Platform Engineering
- Project & Program Management
- Local AI / LLM Systems

## Practice modes
- Learn
- Rehearse
- Assess

## Clients
- Browser/Web
- Terminal/TUI

## Architecture principles
- shared interview core
- evidence-backed scoring
- server-controlled hint behavior
- role-specific workspaces
- adaptive competency graph
- HTTPS/WSS networking
- MCP/API/CLI interoperability
- local-first privacy for optional voice/vision observers
